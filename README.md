# 旋转体体积 · 柱壳法

一个可拖拽的三维交互动画，演示**柱壳法**（Shell Method）的完整推导：

**切条 → 绕 y 轴旋出空心薄壳 → 沿竖缝剪开铺平 → 累加成定积分**

打开网页即可使用：拖拽旋转视角、滚轮缩放，左侧所有参数实时可调。

## 里面有什么

| 模式 | 能看什么 |
|---|---|
| **单个薄壳** | 拖动「推导进度」滑块，看一根竖条怎么转成一个空心圆筒，再像卷轴一样摊平成一块薄板——长 `2πx₀`、高 `f(x₀)`、厚 `dx` |
| **全部薄壳** | 把薄壳数量 `n` 从 1 拖到 200，看阶梯状的黎曼和怎么一点点逼近光滑的旋转体，误差单调趋向 0 |

左下角实时显示 `ΔV = 2π·x₀·f(x₀)·dx` 与展开后薄板的 `长×高×厚`，两个数永远相等。

## 用它

- **在线**：直接打开 Pages 网址，手机上可以「添加到主屏幕」，之后离线也能用
- **离线**：`index.html` 是自包含的，three.js 和字体都已内联，**没有任何外部请求**

## 四条曲线可切换

`√x`、`⅓x²`、`4/x`、`2 + sin 2x` —— 都是无法（或很难）反解出 `x = f⁻¹(y)` 的类型，
正是柱壳法相对圆盘法的用武之地。

## 网址带参数

链接可以记录当前状态，方便发给同学时直接定位到某个画面（注意是 `#` 不是 `?`）：

```
#p=0.78&mode=single&x0=1.7&fx=0     # 单壳模式，停在 78% 进度
#mode=many&n=9&fx=0                 # 累加模式，9 片薄壳
```

参数：`fx` 曲线序号 · `mode` 模式 · `p` 进度 · `x0` 半径 · `dx` 厚度 · `n` 薄壳数 · `solid=1` 叠加精确旋转体

## 技术

单个 HTML 文件，Three.js r128（自写轨道控制，不依赖 OrbitControls），无构建步骤、无依赖安装。
PWA 支持由 `manifest.webmanifest` + `sw.js` 提供。
